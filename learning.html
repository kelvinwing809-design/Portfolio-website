My Learning Journey

Documenting my process, challenges, and key takeaways from building this portfolio with HTML & CSS.

Key Concepts I Learned & Major Challenges

1. HTML Character Entities (&lt; and &gt;)

I learned that certain characters like < and > have special meaning in HTML and cannot be typed directly in text content. To display these characters, I must use HTML character entities: &lt; for the less-than symbol (<) and &gt; for the greater-than symbol (>). This is essential when showing code examples like <header> without the browser interpreting them as actual HTML tags.

Code
                                            <p>This is the &lt;header&gt; tag.</p>
Output
This is the <header> tag.

2. The Inline <code> Element

The <code> element is an inline semantic tag used to define a short piece of computer code. It visually distinguishes code fragments within a paragraph, often displaying them in a monospace font in this case, background and font-color. This was particularly useful for highlighting important elements or keywords directly within my descriptive paragraphs about HTML and CSS concepts.,

Code
                                            Use the <code>div</code> element.
Output
Use the div element.

3. The Block-Level <pre> Element

The <pre> (Preformatted Text) element is a block-level tag that preserves all whitespace and line breaks exactly as they are written in the source HTML file. This is crucial for displaying multi-line code snippets or structured text where exact formatting must be maintained.

Code
                                            <pre>
                                                function main() {
                                                    console.log("Hello!");
                                                }
                                            </pre>
Output
                                                function main() {
                                                    console.log("Hello!");
                                                }

4. CSS z-index for Stacking

The z-index property controls the stacking order of elements that overlap. An element with a higher z-index will always appear in front of an element with a lower value. This was essential for ensuring my icon remained visible above other content.

5. Responsive Design with @media Queries

I implemented @media queriesto make the portfolio responsive. This CSS technique applies different style rules based on device characteristics, such as the screen width (max-width: 768px;). This allows the layout to seamlessly adapt from a desktop view to a mobile view.

6. CSS transform: translateY()

I used the transform property with the translateY() function to create subtle movement effects. By setting a small value like translateY(-4px) on a hover state, I made buttons and cards appear to lift off the page, adding a professional, interactive touch to the UI.

7. CSS Grid Layout System

I learned to use CSS Grid to create the complex, two-dimensional layout for my project gallery and learning cards. It made defining both rows and columns simultaneously simple, giving me precise control over the overall page structure and alignment of my content.

Problem 1: Neon Colors Not Displaying Correctly

I tried to use CSS custom properties (variables) for my neon color theme (--color-primary, --primary-secondary), but they weren't being applied consistently across all elements, with some sections falling back to default colors.

Solution: I discovered I hadn't defined the variables in the :root pseudo-class at the top of my CSS file. After declaring them globally with :root { --color-primary: #00FFFF; }, I could reliably reference them throughout the stylesheet using var(--color-primary).

Problem 2: "Class" Naming Issue

When I want to make changes to the styling from the CSS file, I would occasionally get lost and take a long time to find the specific section I needed to edit. This slowed down my workflow significantly.

Solution: The problem was solved using the Ctrl+Shift-F Search Tool. I can instantly find assigned class name in bothHTMLand CSS files by searching for the class name directly. This drastically improved my efficiency when making style adjustments.

How AI/GenAI helped (requested features, explain code, suggestions)

Code Explanation: Efficient CSS Grid Layout

I used AI assistance to clarify and design in the most efficient way. Once instance was during the making of project gallery grid, I ask Chatgpt to compare manual column definition versus the repeat() function.

My Prompt to AI: "What is the difference between grid-template-columns: 1fr 1fr; and repeat(2, 1fr); in CSS?"
Result: Code and Explanation of Contribution
/* Before AI Suggestion (Manual) */
grid-template-columns:1fr 1fr 1fr 1fr;  

/* After AI Suggestion (DRY Method) */
grid-template-columns: repeat(4, 1fr);

Contribution: The AI confirmed both methods produce the same visual result but suggested using the repeat() function for better readability and adherence to the DRY principle. I adopted this approach to make my CSS cleaner and easier to scale for future projects, moving from repetitive code to the compact repeat(N, 1fr) syntax.
